## 版本说明

依据公开方案研究和三轮独立 Agent 实操，把重复审查改为任务首检与失效重查，完善通用取证、分页与恢复，保留现有名称和默认流程。

## 主要变更

- 明确按任务首次检查、复用证据、相关变化时局部复查，移除深层重复检查冲突，并按采集/签名/资源类型验收。
- 对齐 MCP v1.7.0 的请求对比、响应字节保存、哈希/长度口径、有限快照与错误诊断；强调异步请求已发出后再停止捕获。
- 分页核心新增可选 has_more、空中间页、当前游标有限重试、业务等待以及本次页数上限，CLI支持指定checkpoint，旧默认行为保持兼容。
- 增加改写语义验证、Unicode JSONL消费与多Agent行为评测方法；根据真实失败反馈修正，而不将外部宣传或脚本自检当作任务通过。

## 兼容性

- 保留 hello_js_reverse_skill 名称、模板路径、--resume 和 config.max_pages 的累计语义；--max-pages/新可选项显式启用。
- 核心采集模块只依赖标准库，可接urllib回调；完整CLI仍使用requests。接口成功条件、鉴权、签名与特殊游标语义需要适配。
- 新MCP能力需v1.7.0；旧工作流仍可使用v1.6.x，不要求重编浏览器或开启trace。

## 验证

- 40项Python模板测试、4项脚本/本地HTTP测试、12项Node测试以及39个MCP工具契约校验通过。
- 三轮九个新上下文Agent实操，最终一轮签名、WASM、分页全部通过独立验收；第二轮环境阻塞与各轮辅助脚本失败均保留并反馈修正。
- 本地受控服务与真实Camoufox验证不代表所有网站或长期稳定性通过；验证类型与范围已明确记录。
