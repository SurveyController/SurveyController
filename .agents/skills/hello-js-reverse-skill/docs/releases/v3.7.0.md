## 版本说明

完善可复用的协议采集与改版回归流程，保留现有 Skill 名称和模板路径，默认交付仍为独立 Node.js/Python 程序。

## 主要变更

- 增加可配置的 JSON API 采集入口，支持页码、offset、cursor、去重、JSONL 和页级断点恢复；业务失败和游标循环不会被误认为完成。
- 对齐 MCP v1.6.0 的并发采集、分页导出、Cookie 修复和独立 Node.js 验签，并保存可校验的工具参数快照。
- 修复模板测试入口、VM 地址与定时器、Python Cookie；Node/Python 请求默认不重放 POST，补充三平台离线与本地 HTTP 回归。
- 核心指令改为按需读取，统一工具调用、经验沉淀和验收约定；新增按任务模式的依赖检测与 SDK/签名代码基线脚本。

## 兼容性

- 保留 `hello_js_reverse_skill` 名称、模板目录、`check-deps.sh` 与 `node main.js --test` 入口。
- 旧 MCP 1.5.x 可继续执行原工作流；采集导出、新分页参数和 Node runtime 需 MCP v1.6.0。Python 采集模板可独立运行。
- Node 模板要求 Node.js 18+；Python 新脚本要求 Python 3.10+。旧的临时 Cookie、SDK、密钥和业务字段不会自动迁移。
- `.lock` 用于防止同一输出被并发写入；强制终止后的残留锁需确认旧进程已结束再清理。checkpoint 适用于有界任务。

## 验证

- 四套 Node 模板离线测试 9 项、沙箱和请求重试回归 3 项通过，兼容 `--test` 入口。
- Python 客户端与恢复测试 6 项，基线/依赖脚本和真实本地 HTTP 的 page/offset/cursor 测试 4 项通过；37 个 MCP 工具契约校验通过。
- 未将通用 fixture 测试宣称为真实目标站点或长时间压力测试。
